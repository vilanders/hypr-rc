# Installation
> [!NOTE]
> Make sure you have installed "git" on your pc.

```
git clone https://github.com/vilanders/hypr-rc
cd hypr-rc
./setup.sh
```
# Key bindings
super + Enter = Opens terminal kitty

super + Q = Kills focused window

super + D = Launches the application list menu (rofi)

super + Space = Launches the wallpaper manager (waypaper)

super + F = Opens the file manager (thunar)

super + B = Opens the browser (Zen Browser)

super + ($\rightarrow$, $\leftarrow$, $\uparrow$ or $\downarrow$ keys) = Transfer focus to another window in the same workspace

super + (1,2,3,...,9 keys) = Changes between specified workspaces

super + shift + (1,2,3,...,9 keys) = Change to an specified workspace for an hovered window

super + backspace = logout manager (wlogout)
